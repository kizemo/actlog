## 五、本轮踩到的坑（下个会话必须先知道）

### 5.1 工程坑

1. **`hooks.user_defines` 必须写在 pub workspace 根 `pubspec.yaml`。**
   写在工作区成员包（`packages/core_db/pubspec.yaml`）里会被**静默忽略** —— hook 按仓库根解析配置，成员包里的 define 不生效，表现为 `dart test` 长时间零输出后 exit 65（实为 hook 直连 github.com 超时）。已在根 `pubspec.yaml` 落注释说明原因。
2. **VS 2026（18.7.2）缺 ATL，`flutter_local_notifications_windows` 无条件 `#include <atlbase.h>` → MSB8041。**
   已用「借用本机 VS2022 ATL 的头/库搜索路径」**零安装**绕过。铁律：**禁止把 `atls.lib` 写进 `AdditionalDependencies`**，那才会触发 MSB8041（`Microsoft.CppBuild.targets:506` 判定条件就是「`AdditionalDependencies` 含 `atls.lib` 且 `$(ATL_KeyFile)` 不存在」）。当前补丁只写在 `apps/spike_d1/windows/CMakeLists.txt`，**建 `apps/desktop/` 时必须整体搬过去**，建议抽成 `cmake/atl_borrow.cmake`。
3. **门禁脚本不得硬编码包白名单。** `g1/g2` 曾硬编码 `[string]$Packages='core_domain'`，导致 `core_db` 静默漏检。现已改为默认 `''` + 自动发现 `packages/*/pubspec.yaml`。
4. **门禁脚本必须自带 pub 镜像环境变量**（进程级默认值，调用者优先）。否则慢网下 `dart` 会挂起在连 pub.dev。
5. **`tools/gates/*.ps1` 必须 ASCII-only 且 UTF-8 无 BOM**（防 PowerShell 5.1 用 ANSI 误解码成解析错误）。改完任何 `.ps1`，**先过 AST 语法门禁**再跑：
   ```powershell
   $errs=$null; $null=[System.Management.Automation.Language.Parser]::ParseFile($p,[ref]$null,[ref]$errs); "parse_errors=$($errs.Count)"
   ```
6. **验收脚本读「追加型日志」必须用启动前字节偏移切新段**，否则会被上一轮的完成标记假命中（本轮曾误判 D1 持久化失败）。
7. **`apps/spike_d1/**` 已从根分析上下文 exclude**（`analysis_options.yaml`）。它是**一次性探针**，`apps/desktop/` 落地后连目录一起删。

### 5.2 工具坑（本机安全策略 / PowerShell）

| 动作 | 会被拦的写法 | 可用写法 |
|---|---|---|
| 复制二进制到工作区 | `Copy-Item` / `Copy-Item -Force` | `node -e "fs.copyFileSync('a','b')"` |
| 删除文件 | `Remove-Item` | `rm -- "<绝对路径>"`，**不能**在前后拼 `; "$LASTEXITCODE"`，**不能**先 `cd` |
| 换目录 + 写日志 | `Set-Location x; cmd *> log` 同一命令 | 拆成两条命令 |
| 观察挂起的 `dart test` | 脚本内 `Invoke-Tool` 捕获输出（全程缓冲，挂起时零输出） | 直接后台跑 + `task_output` 流式读 |
| 生成构建脚本 | 中文/非 ASCII `.cmd` | 放 `.superpowers/sdd/*.cmd` 且**纯 ASCII** |

另外：`edit` 工具做「原文替换原文」会返回 `No changes made`，那是正常现象不代表出错；`ghfast.top` 镜像**不稳定**（曾报 `HttpException: Connection closed before full header was received`，也成功过），若 hook 需要重新下载而镜像挂了，备选：改用 `source: system` + `name` 传绝对路径（`sqlite3-3.9.0/doc/hook.md` 原文：*A name containing a directory component is passed to the dynamic loader as-is instead of being turned into a library file name.*）。
