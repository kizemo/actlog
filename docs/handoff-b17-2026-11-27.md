## 7. 本轮新增工具坑（写给下一棒，详见台账 §11.28 六）

1. **台账锚点唯一性会误报**：§11.26 与 §11.27 收尾句完全相同 ⇒ 唯一性断言必然 `exit 3`。正解：取**末条非空行** + 断言其后即文件末尾；插入后独立回读校验「原内容逐字节保留 / 新节标题命中 1 次 / 行尾统一」。
2. `git add` 提示 `CRLF will be replaced by LF` 属**正常**（工作区 CRLF、对象库 LF），不要因此改工作区行尾。
3. 长中文串经 shell 传输会静默吞字 ⇒ 中文正文一律用 `write`/`edit` 工具落盘；commit 信息走 `-F <文件>`。
4. `Set-Location` + 复杂命令会被本地硬安全策略拦 ⇒ 一律绝对路径 + `git -C <abs>`；日志用 `[IO.File]::WriteAllText` 或 `Tee-Object -FilePath`。
5. 不删文件，一律改名归档（`reports\b17-ledger-before-11-28.bak.md` 即插入前归档）。
