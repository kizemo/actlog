## 8. 本轮新增工具坑（写给下一棒，详见台账 §11.29 九）

1. **`tester.getRect` 量的是收缩绘制盒**：蓝图删除按钮量到 **20×20**（图标本身），28×28 命中盒断言必须走 widget 层 `button.constraints?.maxWidth == 28`。
2. **`Semantics(excludeSemantics: true)` 不改变语义节点数**（实测加不加都是 3）⇒ 不能拿节点数变化当证据，用 `b18_blueprint_test.dart` B18-3b 上限断言钉住。
3. **删列必须同步删表头格**，否则行错位；用「表头格数 == 行格数」断言钉住。
4. **多棒并发跑全量会争 `sqlite3.dll`** ⇒ worker 只跑自己写集内的测试文件，权威全量由控制器独占跑。
5. **多棒并发时整包 analyze 会被别的棒污染** ⇒ 控制器复跑 analyze 必须等四棒全部回板。
6. **行尾分家**：台账 = CRLF；`AGENTS.md` 与 `docs\*.md` 计划 = LF ⇒ 台账追加用脚本统一转 CRLF。
7. **`AGENTS.md` 正文不得复述托管块的 BEGIN 标记字面量** —— 一旦正文出现该字面量，提交时「按 BEGIN 字符偏移截断」会命中**首次出现**（正文）而非真块 ⇒ **把 §7.1 与 §8 一并截掉**（B18 实测：正文 L608 + 真块 L665，已改正为真块唯一命中）。正文只写「RELAY-PORT 托管块（BEGIN / END 标记对）」。`docs\*.md` 与台账里复述无害（剥离只作用于 `AGENTS.md`）。
