## 2. 信息架构（自上而下 6 区块）

```
[标题]  关于（t.aboutTitle）
[简介]  一段产品简介（t.aboutIntro）

1. 版本
   ├─ 版本号  0.1.0+1                ← kAppVersionFull
   ├─ [检查更新] [在线升级(禁用)]
   ├─ 禁用原因说明
   └─ 检查结果（四态之一，仅在点过后出现）

2. 仓库
   ├─ URL  https://github.com/kizemo/actlog
   └─ [打开] [复制]

3. 开发者
   ├─ 代号  kizemo
   ├─ 一句话介绍
   └─ [https://github.com/kizemo]

4. 其它软件
   ├─ Alpha File Manager + [链接]
   └─ PageWeaver + [未核实标注] + [链接]
```

区块顺序**即语义顺序**：先「这是什么版本」，再「从哪来」，再「谁做的」，最后「还做了什么」。
这个顺序不许调换 —— 前三个区块回答用户的直接疑问，第四个是延伸。

## 3. 设计规格

### 3.1 色彩（全部来自 `theme\app_tokens.dart`，零新色）

| 用途 | Token | 取值 | 定义行 |
|---|---|---|---|
| 页面底色（深链宿主） | `paper` | `#F6F4EF` | `app_tokens.dart:11` |
| 标题 / 区块标题 / 启用态按钮字 | `ink` | `#322B23` | `:35` |
| 正文段落 | `ink2` | `#4A4036` | `:40` |
| 说明文字 / 机器可读文字 | `meta` | `#5F584B` | `:43` |
| 禁用态按钮字 | `faint` | `#6E6759` | `:46` |
| 禁用态按钮边 | `hair` | `#DCD5C6` | `:49` |
| 启用态按钮边 | `hairStrong` | `#8A8170` | `:57` |
| 留作语义强调（本页暂未使用） | `accentInk` | `#7A4E24` | `:63` |

**注意**：`hair` 在本项目只承载**纯装饰**（`docs\task40\模块优化建议` 引用的 `TOKENS.md §1.6` 口径）；
关于页把它用在**禁用态按钮边框**上是有意的 —— 禁用按钮不是可交互边界，用弱边表达「这里按不下去」。
反过来说，**启用态必须是 `hairStrong`**，不许用 `hair`，否则用户分不清哪个能点。

### 3.2 字号与行高

| 元素 | 字号 / 行高 / 字重 | 字族 | 色 | 位置 |
|---|---|---|---|---|
| 页面标题 | `titleLarge`（主题默认） | `AppFonts.body` + fallback | `ink` | `about_page.dart:96-103` |
| 区块标题 | 13 / 1.4 / `w600` | `AppFonts.body` | `ink` | `:240-255`（`:248-251` 是四元组） |
| 正文段落 | 13 / 1.6 / 常规 | `AppFonts.body` | `ink2` | `:301-307` |
| 说明文字 | 12 / 1.5 / 常规 | `AppFonts.body` | `meta` | `:310-316` |
| 机器可读（URL / 版本 / 结果） | 11 / 1.4 / 常规 | `AppFonts.mono` | `meta`（版本号用 `ink2`） | `:319-325` |
| 按钮文字 | 12 / 1.2 / 常规 | `AppFonts.body` | `ink` / 禁用 `faint` | `:285-294` |

三条口径：
1. **URL 必须用 mono**（`:319-325`），因为用户可能要逐字核对或抄写。
2. **版本号用 mono + `ink2`**（`about_page.dart:116`），比 URL 高一级 —— 版本号是本页最常被查的一项。
3. 正文与区块标题**同为 13 号**，靠字重（`w600`）和颜色（`ink` vs `ink2`）分层，不靠字号 —— 这是本项目的密度纪律。

### 3.3 间距节奏

| 位置 | 值 | Token | 位置 |
|---|---|---|---|
| 标题 → 简介 | 22 | `gapSec` | `:104` |
| 简介 → 第一区块 | 12 | `gapCard` | `:109` |
| 区块 → 下一区块 | 12 | `gapCard` | `:152` / `:179` / `:200` |
| 区块标题 → 内容 | 22（`_sectionTitle` 的 bottom padding） | `gapSec` | `:242` |
| 版本号 → 按钮组 | 22 | `gapSec` | `:118` |
| 按钮组 → 禁用原因 | 6 | 字面量 | `:137` |
| 开发者名 → 介绍 | 4 | 字面量 | `:188` |
| 介绍 → 链接 | 22 | `gapSec` | `:193` |
| 按钮之间（横/纵） | 8 / 8 | `Wrap.spacing/runSpacing` | `:120-121` / `:163-164` |

**规律**：`gapCard`(=12) 是**同级分隔**，`gapSec`(=22) 是**主次分隔**。4 / 6 两个字面量只用于
「同一句话的两行」，属于段内微调，不提升为 token。

### 3.4 按钮规格

| 属性 | 启用态 | 禁用态 |
|---|---|---|
| 外边距 | `padding: h12 v7` | 同 |
| 圆角 | `AppTokens.radius` = **4**（`app_tokens.dart:66`） | 同 |
| 边框 | 1px `hairStrong` `#8A8170` | 1px `hair` `#DCD5C6` |
| 文字 | 12 / 1.2，`ink` `#322B23` | 12 / 1.2，`faint` `#6E6759` |
| 交互 | `InkWell` 点击 | `onTap == null` |
| 禁用判据 | `onTap != null` ⇒ 启用 | `:272` 的 `enabled` |

**为什么不用 `TextButton`**：`TextButton` 自带主题内边距与水波纹形状，与「账页」视觉不兼容；`_LinkButton`
（`:259`）是刻意做的一个薄封装。代价是键盘可达性（见差距 G6）。

### 3.6 交互规格

| 交互 | 行为 | 位置 |
|---|---|---|
| 点「检查更新」 | `_checking = true` → 按钮文案换 `t.checking` → 请求 → `mounted` 保护 → 回填结果 | `:37-56` |
| 重复点击 | `_checking` 期间直接 return（不做二次请求） | `:38-40` |
| 离开页面 | `!mounted` 直接 return，不写 state | `:49-51` / `:60-62` |
| 检查结果 | 四态：`upToDate` / `newer`（带版本号）/ `noRelease` / `networkError` | `:73-81` |
| 「在线升级」 | `onTap: null` 恒禁用，并给可见原因 | `:130-142` |
| 「复制」 | `Clipboard.setData` 后 `_copied = true`，按钮文案换 `t.copied` | `:58-66` / `:173` |
| 打开链接 | `systemIntegrationProvider.openUrl`（零新增依赖） | `:68-70` |

**两条不许妥协的规则**：
1. **在线升级不许伪造下载链接**。仓库当前 0 个 release，就必须禁用并说明原因（`:128-129` 注释写死了这条）。
2. **四种检查结果都必须有话说**，404 与网络失败都不许静默（`:72` 注释）。

## 7. 待补项的具体规格

### 7.1 G6 + G7 · 键盘可达与 focus 态（P0）

**问题**：`:273` 的 `InkWell` 没有焦点节点。关于页共 8 枚 `_LinkButton`（`:124` / `:131` / `:167` /
`:172` / `:195` / `:210` / `:231`，其中 `:131` 恒禁用），纯键盘用户无法触达任何一枚。

**规格**
1. 保留 `_LinkButton` 名称与全部 14 枚 key（§4），只换内部实现。
2. 首选：改为 `FocusableActionDetector` + `InkWell`，`onShowFocusHighlight` 置 `_focused`。
3. 边框色三态：`focus` → `ink`（`#322B23`）；`hover` → `hairStrong`（`#8A8170`）；默认 → `hairStrong`；
   禁用 → `hair`（`#DCD5C6`）。
4. 禁用按钮不进 Tab 序（`enabled` 为 false 时不注册焦点）。
5. **不新增色值**：`ink` 与 `hairStrong` 都在 `app_tokens.dart:35` / `:57` 已定义。

**验收**
- 键盘 Tab 从页面顶部可依次到达 7 枚可用按钮，禁用按钮被跳过；
- 断言 focus 态边框 `Color` ≠ hover 态边框 `Color`。

### 7.2 G3 · 数据与隐私说明（P0）

**为什么是 P0**：这是本页唯一会让用户对系统产生「它到底把我的东西放哪了」疑虑的缺口，
而本项目是**纯本地**应用，说明成本极低、收益极高。

**规格**
- 位置：仓库区块（`:154`）之前，作为第 2 区块。
- 标题：`数据与隐私`；正文：正文样式（13/1.6 `ink2`）。
- 内容必须逐字为真：① 数据存于本机 SQLite；② 除「检查更新」访问 GitHub releases API 外不发起网络请求；
  ③ 无账号、无遥测。**不许写「我们重视您的隐私」这类空话**。
- 新增 key：`about-privacy`。

### 7.3 G1 / G2 / G5 · 新增区块与动作（P1）

| 项 | 位置 | 样式 | 新 key |
|---|---|---|---|
| 最近变更 | 版本区块之后 | 区块标题 + 正文段落（多条短句） | `about-changelog` |
| 许可证 | 「其它软件」之后（末块） | 区块标题 + 说明文字（12/1.5 `meta`） | `about-licenses` |

**许可证区块的诚实纪律**：只列**实际存在**的依赖。当前 `pubspec` 里的事实依赖是 Flutter SDK 与
本项目自有的 `core_domain` / `core_db` / `core_data` 三个包；第三方库须逐个核对 `pubspec.yaml` 后再写，
